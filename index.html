PROJECT FILE / 项目简介

男频逆袭叙事与西方雷神神话的融合。故事围绕雷神血脉带来的身份转折与能力成长展开，通过不断升级的冲突、能力体系与奇幻视觉，形成节奏紧凑的高燃成长体验。

执行导演｜制作流程与重点集落地

从前期样片验证进入正片批量落地，统筹40集内容排期与任务分配，协调3名AI生成制作和2名剪辑并行推进。重点负责高燃集数的镜头呈现、奇幻视效、关键资产及成片质量审核，并将项目经验沉淀为标准化制作SOP，支持团队在约两周内完成交付。

PROJECT FILE / 项目简介
